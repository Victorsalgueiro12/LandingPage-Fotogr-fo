#  Abel Rocha Content — Landing Page

Landing page desenvolvida para um profissional de fotografia e produção audiovisual, com foco na apresentação de portfólio, divulgação de serviços e captação de clientes por meio de solicitações de orçamento.

🔗 **Projeto online:** [abelrocharcontent.netlify.app](https://abelrocharcontent.netlify.app/)

##  Sobre o projeto

O objetivo do projeto é oferecer uma presença digital profissional para o fotógrafo, valorizando seus trabalhos, apresentando seus serviços e facilitando o contato com potenciais clientes.

A interface foi planejada para proporcionar uma navegação intuitiva, destacar o conteúdo visual e direcionar os visitantes para o contato comercial.

##  Funcionalidades

- **Portfólio audiovisual:** apresentação de trabalhos fotográficos e produções em vídeo.
- **Apresentação profissional:** divulgação do profissional e de suas áreas de atuação.
- **Exibição de serviços:** organização dos serviços oferecidos para facilitar a compreensão dos clientes.
- **Captação de orçamentos:** chamadas para ação direcionadas a potenciais clientes.
- **Integração com WhatsApp:** acesso direto ao canal de contato para consultas e solicitações de orçamento.
- **Design responsivo:** adaptação da interface a diferentes tamanhos de tela.
- **Identidade visual personalizada:** layout desenvolvido para valorizar a marca
